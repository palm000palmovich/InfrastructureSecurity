Практические задания

**Задание 1:** Анализ мисконфигураций

Необходимо создать и проанализировать:

    -3 примера мисконфигураций sudo (чтение, запись, исполнение)
    -3 примера мисконфигураций SUID/SGID (аналогично)

Для каждого случая нужно:

    -Описать причину возникновения уязвимости
    -Объяснить способ эксплуатации
    -Предложить меры по устранению


**Задание 2:** Настройка безопасности

Требуется выполнить:

    -Создание отдельного аккаунта администратора с доступом через sudo
    -Отключение прямого входа под root
    -Запрет ssh-доступа для root
    -Настройка UMASK и HOME_MODE
    -Внедрение парольной политики по ГОСТ 57580.1
    -Установка неизменяемости на конфигурационный файл
    -Настройка ACL на директорию
